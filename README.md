# React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

At its core, an eCommerce web app connects:

Customers (buyers)
Sellers/Admins (product managers)
System backend (business logic + database)

So users can:

Browse products
Add items to cart
Place orders


Authentication & Security
Password hashing (bcrypt)
JWT tokens
Role-based access (user/admin)

It is simple app as it indicate the helpful webapp for ecommerce activities.
